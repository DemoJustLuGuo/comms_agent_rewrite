# 工程评估速查（噪声 / 灵敏度 / 干扰 / 衰落）

> 面向链路工程评估的口径速查。定量计算一律交给域工具（rf_chain / interference /
> channel_profile / fade_margin），本表提供公式口径、典型值与经验门限。

## 1. 噪声与灵敏度

### 基本公式
- 热噪声底：`N(dBm) = -174 + 10·log10(B_Hz)`（T=290 K；-174 dBm/Hz 即 kT）
- 接收灵敏度：`S(dBm) = -174 + 10·log10(B) + NF + SNR_req`
- Friis 级联噪声系数（线性值）：`F = F1 + (F2-1)/G1 + (F3-1)/(G1·G2) + ...`
  → **第一级（LNA）的 NF 和增益主导整链**；LNA 之前的每 1 dB 损耗直接加 1 dB 系统 NF。

### 典型噪声系数（NF）
| 器件 | 典型 NF |
|---|---|
| 优质 LNA（Sub-6G） | 0.5 ~ 1.5 dB |
| 普通 LNA / 集成接收前端 | 2 ~ 4 dB |
| 混频器（无源） | 6 ~ 9 dB（≈变频损耗） |
| 同轴线缆/连接器 | NF = 插损（无源件，每米 0.1~1 dB 看频段） |
| 手机/终端整机 | 5 ~ 9 dB |
| 基站接收机整机 | 2 ~ 5 dB |

### 常见制式灵敏度参考（量级感）
| 制式 | 带宽 | 典型灵敏度 |
|---|---|---|
| GSM 语音 | 200 kHz | ≈ -104 dBm（终端） |
| LTE 5 MHz QPSK | 4.5 MHz | ≈ -100 dBm |
| WiFi 802.11n 20 MHz MCS0 | 20 MHz | ≈ -82 dBm |
| WiFi 高阶 MCS（64QAM+） | 20 MHz | ≈ -65 ~ -70 dBm |
| GPS L1 C/A | 2 MHz | ≈ -130 dBm（扩频增益补偿） |

## 2. 所需 SNR / C/I 门限（经验值，AWGN 解调门限量级）
| 调制/场景 | 所需 SNR（近似） |
|---|---|
| BPSK/QPSK（BER 1e-3，未编码） | 7 ~ 10 dB |
| 16QAM | 14 ~ 17 dB |
| 64QAM | 20 ~ 24 dB |
| 256QAM | 26 ~ 30 dB |
| GSM 共道 C/I 规划门限 | ≥ 9 dB（工程常用 12 dB） |
| LTE 边缘 SINR 规划 | -3 ~ 0 dB（QPSK 低码率） |

注意：现代制式带 FEC，实际门限比未编码理论低数 dB——精确值用 channel_coding 工具仿真，不要拍脑袋。

## 3. 衰落余量经验值（链路预算预留）
| 场景 | 建议余量 |
|---|---|
| 固定视距微波（晴空多径） | 20 ~ 40 dB（看可用度目标与跳距） |
| 蜂窝宏站（阴影衰落，对数正态 σ≈8 dB） | 8 ~ 12 dB（90%~95% 边缘覆盖率） |
| 室内穿透 | 额外 10 ~ 20 dB（混凝土墙单面 10~15 dB） |
| 快衰落（瑞利，未分集） | 99% 可靠需 ≈20 dB；有分集/HARQ 可大幅压缩 |
| 毫米波雨衰（短跳 <5 km，23~38 GHz） | 10 ~ 30 dB 看雨区（用 fade_margin rain 估算） |

## 4. 多普勒与相干量纲（channel_profile 口径）
- 最大多普勒频移：`fd = v·f/c`（120 km/h @ 2.6 GHz ≈ 289 Hz）
- 相干时间：`Tc ≈ 0.423/fd`（Clarke 模型）；`Ts << Tc` → 慢衰落
- 相干带宽：`Bc ≈ 1/(5·στ)`（50% 相关）；`B << Bc` → 平坦衰落
- 典型 RMS 时延扩展：室内 10~100 ns；市区 0.5~3 μs（Bc≈70k~400kHz）；山区可 >10 μs
- 工程含义：频选信道 → OFDM/均衡器；快衰落 → 交织+FEC、导频密度加大

## 5. 干扰计算注意（interference 口径）
- 多干扰源必须**线性域（mW）叠加**再回 dB，禁止直接把 dBm 相加。
- 邻道干扰要计入 ACS（接收机邻道选择性）/ACLR（发射邻道泄漏比）折算后的等效功率。
- SINR = C / (I_total + N)；干扰受限场景（I >> N）下加功率无益，要靠隔离度/频率复用。
