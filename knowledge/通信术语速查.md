# 通信术语速查（示例知识库）

> P0 示例知识。`comms-qa` 问答模式应优先检索本文件回答专业名词。

## FSPL（Free-Space Path Loss，自由空间路径损耗）
电磁波在自由空间传播时仅因能量扩散造成的损耗。常用工程公式（d 单位 km、f 单位 MHz）：
`FSPL(dB) = 20·log10(d_km) + 20·log10(f_MHz) + 32.44`。

## EIRP（Equivalent Isotropically Radiated Power，等效全向辐射功率）
`EIRP(dBm) = 发射功率(dBm) + 发射天线增益(dBi)`。表征发射端等效到全向天线的辐射能力。

## 链路预算（Link Budget）
对发射到接收全链路的增益与损耗求和，估算接收功率：
`Prx(dBm) = EIRP + Grx − FSPL − 其他损耗`。用于评估链路是否可建立。

## 链路余量（Link Margin）
`链路余量(dB) = 接收功率(dBm) − 接收灵敏度(dBm)`。>0 表示链路可建立，越大越稳健。

## SNR（Signal-to-Noise Ratio，信噪比）
信号功率与噪声功率之比，常用 dB 表示。决定可达速率与误码率的关键指标之一。

## Eb/N0（每比特能量与噪声功率谱密度之比）
数字通信中衡量解调性能的归一化指标，与 SNR 通过带宽和比特率换算：
`SNR = (Eb/N0)·(Rb/B)`，Rb 为比特率，B 为带宽。

## Noise Floor（底噪）
接收系统本底噪声功率：`N(dBm) ≈ −174 + 10·log10(B_Hz) + NF(dB)`，NF 为噪声系数。
