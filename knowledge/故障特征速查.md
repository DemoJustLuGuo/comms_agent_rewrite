# 故障特征速查（症状 → 可能原因）

> /diagnose 与 signal_diagnose 工具的对照依据：先用工具量化指标，再按本表把
> 症状映射到可能原因（按常见度排序），给出下一步排查动作。

## 1. 时域/统计类症状

| 症状（signal_diagnose 指标） | 可能原因（按常见度） | 下一步排查 |
|---|---|---|
| DC 偏置显著（>5% RMS） | ①零中频接收机本振泄漏 ②ADC 偏置未校准 ③直流耦合链路的偏置漂移 | 断开射频输入看偏置是否仍在（在→ADC/基带；消失→LO 泄漏）；查校准流程 |
| 削波/平顶（贴满幅+连续平顶段） | ①前端增益过大/AGC 失效 ②ADC 满量程配置错 ③强干扰顶饱和 | 降增益复测；查 AGC 状态字；看频谱有无异常强信号 |
| 峰均比异常低（<3 dB 且非恒包络调制） | 削波或限幅已发生 | 同削波排查 |
| 峰均比异常高（>15 dB） | ①脉冲干扰混入 ②突发/猝发信号 ③采样丢点拼接 | 看时域波形定位脉冲；查采集链路丢包计数 |

## 2. 频域类症状

| 症状 | 可能原因 | 下一步排查 |
|---|---|---|
| 谐波失真高（THD >5%，H2/H3 突出） | ①放大器压缩（P1dB 附近工作）②削波 ③器件非线性 | 回退输入功率看谐波是否按 2:1/3:1 dB 退化（是→非线性确认） |
| 互调杂散（非谐波位置成对出现） | ①双音/多载波过非线性器件（IMD3）②无源互调 PIM（连接器/锈蚀） | 算杂散频率是否 = 2f1-f2 组合；PIM 用单载波逐一排除 |
| 本振泄漏（载频中心一根固定谱线） | 零中频发射机 LO 馈通、IQ 调制器偏置失调 | 调 IQ 调制器直流偏置；看谱线是否随基带静默仍存在 |
| 镜像分量（关于载频/中心对称的副本） | IQ 幅度/相位失衡（见下） | signal_diagnose 用 i+q 双路量化失衡度 |
| 相位噪声裙（谱线两侧连续裙边） | ①本振相噪差 ②参考时钟劣化 ③锁相环带宽设置不当 | 换参考源对比；看裙边转折频率对应环路带宽 |
| 杂散单根且频率固定 | ①时钟谐波串扰 ②开关电源纹波调制 ③邻近设备干扰 | 杂散频率除以已知时钟频率找整数关系；关邻设备复测 |

## 3. IQ/星座类症状

| 症状 | 可能原因 | 工程含义 |
|---|---|---|
| IQ 幅度失衡 >0.5 dB 或相位失衡 >2° | IQ 调制/解调器不平衡、滤波器不对称 | 产生镜像抑制恶化（IRR ≈ -20log10(失衡量)），高阶 QAM EVM 明显劣化 |
| 星座整体旋转（缓慢） | 载波频偏残留（CFO 未校净） | 每符号旋转角 = 2π·Δf·Ts；先做频偏估计 |
| 星座旋转弥散（角向拉花） | 相位噪声 | 区别于 CFO：弥散是随机的、不累积 |
| 星座径向压缩（外圈点内缩） | 放大器 AM/AM 压缩 | 高阶 QAM 外圈点先坏；查 PA 回退量 |
| 星座整体缩放/漂移 | AGC 波动、参考电平错 | 看帧内 EVM 是否随时间漂移 |

## 4. 误码/链路类症状（配合 ber_snr / channel / channel_coding 工具）

| 症状 | 可能原因 | 下一步排查 |
|---|---|---|
| 实测 BER 远差于该 SNR 理论值（>2 个数量级） | ①SNR 估计口径错（Es/N0 vs Eb/N0）②频选信道未均衡 ③同步残差（定时/频偏） | 用 ber_snr 对齐口径；channel_profile 判平坦/频选；查同步环路 |
| BER 地板（SNR 再高也不降） | ①IQ 失衡/相噪等乘性损伤 ②量化位数不足 ③码间串扰残留 | signal_diagnose 量化失衡；看星座是否 SNR 无关地弥散 |
| 突发误码（平时干净，间歇成串） | ①脉冲干扰 ②衰落深谷（余量不足）③设备温度/供电事件 | 误码时间戳与干扰/衰落记录对齐；查交织+FEC 配置是否覆盖突发长度 |
| 丢帧但 BER 正常 | ①帧同步字被击中 ②CRC 校验口径不一致 ③缓冲溢出 | frame_parser 校验帧结构与 CRC 约定 |

## 5. 排查通用顺序

1. **先量化**：signal_diagnose 拿指标（DC/削波/THD/SNR/IQ 失衡），不凭肉眼。
2. **分段定位**：射频前端 → ADC/采集 → 基带算法，逐段断开或注入已知信号。
3. **单变量**：一次只改一个条件（增益/频点/线缆/参考源）。
4. **对照理论**：ber_snr/channel 给理论基线，偏差方向指示损伤类型。
5. **留证据**：signal_analysis/plot 存频谱与星座 PNG，前后对比。
