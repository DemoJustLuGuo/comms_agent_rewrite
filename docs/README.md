# Agent-facing docs

本目录只保留智能体运行和优化真实项目时可能需要读取的文档。

- `real_project_integration.md`：当前真实通信项目的路径、允许修改范围、验证命令和首轮优化边界。
- `optimize_loop_validation.md`：`/optimize-loop` 的人工审批闭环流程、验证步骤和执行记录。
- `model_output_review_checklist.md`：审阅模型产物是否保留或回退的检查清单。

不要把本目录当通信专业知识库。通信概念、公式、术语优先读取 `../knowledge/`。

开发进度、验收、命令速查、模型路由验证和 UI 评估等项目运维文档已经移到仓库根目录 `../../docs/`。
